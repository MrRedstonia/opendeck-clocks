# OpenDeck Clocks

Customizable digital and analog clocks showing local time and date on a key.

Clocks adds two actions to [OpenDeck](https://github.com/nekename/OpenDeck) that turn any key into a live clock.

⚠️ **The plugin *might* work on the official Stream Deck app, but has not been tested** ⚠️
