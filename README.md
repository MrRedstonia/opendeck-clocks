# OpenDeck Clocks

Customizable digital and analog clocks showing local time and date on a key.

Clocks adds two actions to [OpenDeck](https://github.com/nekename/OpenDeck) that turn any key into a live clock.

⚠️ **The plugin *might* work on the official Stream Deck app, but is not officially supported** ⚠️

![Clocks](assets/screenshot.png)

### Installation
1. Download the `com.mrredstonia.clocks.streamDeckPlugin` file
2. Open the `Plugins` menu in OpenDeck
3. Click 'Install from file'
4. Select the downloaded `com.mrredstonia.clocks.streamDeckPlugin` file.
